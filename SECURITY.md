# Security Policy

Please disclose potential security issues privately through GitHub's **Report a vulnerability** feature in the Security tab, if enabled. If that option is unavailable, contact the maintainer privately rather than publishing exploit details.

Provide steps to reproduce, impact, affected browsers or versions, and suggested mitigations. Do not share sensitive data or credentials in public issues.

The app is a client-side project. Optional music and video features may load third-party providers, whose privacy and security practices are separate from this repository.

There is no guaranteed response or fix timeline.
