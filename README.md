# Baby Contrast Cards

A calm, simple, mobile-friendly collection of high-contrast black-and-white visual cards.

## Features

- 12 original SVG cards: shapes, stripes, checkerboards, circles, zigzags, and more
- Previous / Next navigation, card dots, and Surprise button
- Collections for all cards, shapes, and patterns
- Full-screen viewing mode
- Responsive layout for phones and tablets
- No dependencies, account, tracking, or advertisements

## Run it

Open `index.html` in a browser, or publish the repository with GitHub Pages.

## Publish with GitHub Pages

1. Open the repository's **Settings** tab.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then tap **Save**.
5. After deployment finishes, the site URL will appear in the Pages section.

## A gentle reminder

Use these cards during short, supervised moments. Keep the screen at a comfortable distance, take breaks, and stop if your baby looks away or seems uncomfortable. This project is for visual play and is not medical advice.
